# 🎮 Таймер для детей

Настраиваемый таймер с фоном из игры, сделанный для сына.

## Возможности

- Выставляй часы и минуты
- По умолчанию 5 минут
- Всегда поверх всех окон
- Нельзя закрыть пока таймер идёт
- При старте сворачивается в маленькое окошко — не мешает играть
- Маленькое окошко можно перетаскивать мышкой куда угодно
- За 2 минуты до конца — предупреждающий звук
- По окончании — звук + блокировка экрана (Win+L)
- Защита от двойного запуска

## Запуск

Двойной клик на `timer.vbs` — запускается без консоли.

## Требования

- Windows
- Python 3.x + Pillow (`pip install pillow`)
